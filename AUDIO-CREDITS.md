# Audio credits

Every file in `public/audio/sfx/` and `public/audio/ir/` is CC0 1.0 or public domain. Masters live in
`audio-src/`; `npm run process-audio` regenerates the shipped files (trim leading silence, loudnorm to
-16 LUFS, mono, Ogg Vorbis q5; ambience is not trimmed; the IR is only re-encoded).

Pools marked "pending, CC0 search failed" are stubs with no files; the game skips that layer.

## Booth announcer clips (`public/audio/announcers/`)

Generated by `npm run bake-audio` (`scripts/bake-audio.mjs`) from `src/audio/announcer-lines.json`.

- Engine: [edge-tts](https://github.com/rany2/edge-tts) (LGPL-3.0 / GPL-3.0 tool) calling Microsoft Edge neural text-to-speech voices. Used offline at bake time only; the app ships and plays the resulting MP3 files and never calls a TTS service for the booth.
- Big Red Brannigan: `en-US-GuyNeural` (rate +6%, pitch -6Hz).
- Smooth Eddie Breeze: `en-US-BrianNeural` (rate -8%, pitch -2Hz).
- Characters and lines are original; no real announcer or celebrity voice is imitated.
- Voice output is subject to Microsoft's terms for its speech services. For a public/commercial release, consider re-baking with a voice whose license explicitly covers redistribution (the script takes a voice config at the top).
- Placeholders are baked as fixed stand-ins: `{word}` → "that spelling", `{runs}` → "2", `{inning}` → "3".

## Spelling-word clips (baked live, `/audio/words/`)

Generated on the live server, not at build time. When a parent creates or edits a word list, the server
bakes a normal, slow, and (if present) sentence clip for each word in the background and stores them in
Replit App Storage under `word-audio/{sha256}.mp3` (see `server/src/word-audio/`).

- Engine: [msedge-tts](https://www.npmjs.com/package/msedge-tts) (MIT) calling Microsoft Edge's **unofficial**
  "Read aloud" neural text-to-speech endpoint from the live server. This is not a supported Microsoft API: it can
  change, rate-limit, or stop working without notice, and use from a server is outside its intended purpose.
  Brandon chose to accept that risk on 2026-10-30.
- Voice: `en-US-JennyNeural` (word -10%, slow -45%, sentence -5%; pitch +0Hz).
- Text is the parent's own word list; no child data is sent.
- If baking fails or a clip is not ready, the game uses the device's browser voice (`src/audio/speech.ts`).
  Local mode (no server) always uses browser speech.
- To swap engines, implement the `Synth` type in `server/src/word-audio/baker.ts` (for example with
  `edge-tts-universal`, or a licensed cloud TTS) and change `CLIP_PROFILES` so old clip hashes are not reused.
- Set `WORD_AUDIO=off` to disable live baking entirely.
